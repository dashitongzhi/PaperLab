# Paper Submit

Package the approved paper.

## Workflow

1. **Venue template** — MethodsX / JOSS / SoftwareX / arXiv preprint style; adapt metadata, highlights, and cover letter.
2. **Compile** — build the PDF; zero errors, zero unresolved references (`??` blocks submission).
3. **Package** — manuscript + figures + bib + cover letter + the full evidence bundle (ledger, citation verifications, traceability) under `submission/`.
4. **Final gate** — the submission decision is always human. Record the decision and conditions.

## Gate

STOP after packaging. Never submit anywhere without the human's recorded approval.
