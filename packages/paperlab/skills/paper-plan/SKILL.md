# Paper Plan

Write the plan that every later stage is audited against.

## Workflow

1. **Question** — one falsifiable question with its variables and interactions named ("for identical packet-loss counts, how do burst length, observer fallback and plant mismatch interact?"). Not a topic word.
2. **Established foundations** — name the known results the work builds on. If prediction during losses is not new, say so.
3. **Design** — benchmarks, baselines, what is held constant across policies, and the commitment to publish unfavorable results.
4. **Deliverables** — exact artifact list (PDF, source, raw CSV, figures, bibliography, reading list, publication-gap report).
5. **Forbidden claims** — explicit list of what this work must NOT claim (e.g. "do not treat simulated packet loss as a designed optimal cyberattack"; "a toy example is not a trained-policy result").

## Gate

Present the plan and stop. The topic gate requires the human's approval of this plan.
